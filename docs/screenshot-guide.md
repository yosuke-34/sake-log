# Google Play 用スクリーンショット撮影ガイド

Google Play Console には**最低2枚、最大8枚**のスクリーンショットが必要です。
ストア検索結果でユーザーが最初に見る視覚情報なので、最も重要な素材です。

---

## 推奨サイズ

- **スマホ用**: 1080×1920（FHD・縦）または 1080×2400（FHD+・縦）
- **比率**: 9:16〜9:19.5 程度（縦長）
- **形式**: PNG または JPEG（PNG推奨）
- **最小サイズ**: 320px、最大: 3840px

---

## 撮影方法（3つの選択肢）

### 方法A: Chromeデベロッパーツール（推奨・簡単）

1. PC で Chrome を開く
2. https://sake-log-two.vercel.app/ にアクセス
3. F12 でデベロッパーツールを起動
4. デバイスツールバー（Ctrl+Shift+M）を押す
5. 端末を「Pixel 7」または「iPhone 14 Pro Max」に設定
6. 画面右上の「︙」→「Capture screenshot」でスクショ撮影
7. 自動的に1080×2400相当の画像が保存される

### 方法B: 実機（Android）で撮影

1. Pixel・Galaxy などのAndroid端末で `sake-log-two.vercel.app` を開く
2. 「ホーム画面に追加」でPWAインストール
3. アプリを起動して各画面で電源+音量下キーでスクリーンショット
4. PCに転送

### 方法C: iPhone で撮影（Android用に流用可）

1. iPhone Safariで開いてホーム画面に追加
2. アプリ起動して電源+音量上キーでスクリーンショット
3. 1290×2796 などのサイズで撮れるので、トリミングなしでOK

## 撮影する8枚の構成（推奨）

### 📸 1枚目：ランディングページ（トップ）
- **URL**: `/`
- **画面**: ヒーロー部分「お酒の楽しみ方を、もっと深く。」が見える状態
- **目的**: アプリの世界観を一目で伝える
- **撮影前操作**: localStorageを削除（DevToolsで `localStorage.clear()`）して初回訪問状態に

### 📸 2枚目：カレンダー画面
- **URL**: `/calendar`
- **画面**: 「2026年X月」の月表示、いくつかの日付に記録あり（赤丸）
- **目的**: 主要機能を視覚化
- **撮影前操作**: 数件のデータを記録しておく（焼酎・日本酒・ウイスキーなど）

### 📸 3枚目：記録追加画面
- **URL**: `/add`
- **画面**: 酒種選択（🍶日本酒・🍺ビール…）と銘柄入力中の状態
- **目的**: 「気軽に記録できる」操作感を訴求

### 📸 4枚目：飲酒量統計
- **URL**: `/calendar`（飲酒量タブ）
- **画面**: 週・月の純アルコール量グラフ表示
- **目的**: 健康管理機能をアピール

### 📸 5枚目：銘柄図鑑
- **URL**: `/calendar`（図鑑タブ）
- **画面**: 都道府県マップで色付きの県がいくつかある状態
- **目的**: コレクション要素・地理ビジュアル

### 📸 6枚目：銘柄詳細（本ページ）
- **画面**: 図鑑からタップして開く銘柄詳細ページ（楽天・Amazonリンク付き）
- **目的**: アフィリエイト導線の自然さを示す

### 📸 7枚目：お酒コラム（日本酒）
- **URL**: `/columns/sake-basics`
- **画面**: 「定番銘柄ガイド」が見える位置、楽天/Amazonボタンが入った銘柄カード
- **目的**: メディア性・読み物としての価値を訴求

### 📸 8枚目：適正飲酒ガイド
- **URL**: `/responsible-drinking`
- **画面**: 純アルコール量計算式や注意喚起が見える位置
- **目的**: 「責任ある運営」を示し、レーティング審査でも好印象

## 撮影前の準備チェックリスト

- [ ] サンプル用の飲酒記録を5〜10件入力（日本酒・ウイスキー・ビール・ワイン・焼酎を含める）
- [ ] 銘柄は実在のもの（八海山、山崎、ヱビス、シャブリ、いいちこ等）にする
- [ ] 写真があるとリアル感が出るので、お酒の写真を数枚アップ
- [ ] DevToolsで「Pixel 7（412×915）」または「iPhone 14 Pro（393×852）」を選択
- [ ] アドレスバー・ステータスバーを写し込まない設定（DevToolsはOKだが実機は注意）

---

## 各画面の見栄えチェック

撮影前に必ず確認：

| 項目 | 良い例 | 悪い例 |
|---|---|---|
| ローディング状態 | 表示完了状態 | 「読み込み中」表示 |
| エラー | エラー無し | 赤いエラーバナー |
| 空の状態 | コンテンツあり | 「記録がありません」 |
| 銘柄名 | 八海山、山崎12年 | テスト1、aaa |
| 飲酒量 | 350ml、180ml | 999999999ml |

## 機能グラフィック（1枚追加で必要）

スクショとは別に**機能グラフィック（Feature Graphic）**が1枚必須です。

- **サイズ**: 1024×500 PNG
- **内容**: アプリのキービジュアル（タイトル＋スクショ合成等）
- **作成方法**:
  - Canva (https://www.canva.com/) のテンプレートが便利
  - 「Google Play Feature Graphic」で検索
  - 暖簾デザインの色（#C53D43）を活かす

サンプルレイアウト例：
```
┌─────────────────────────────────────┐
│  🍶 酒ログ                          │
│                                       │
│  お酒の記録と知識、ひとつに。       │
│                                       │
│  [スマホスクショ画像] [テキスト]   │
└─────────────────────────────────────┘
```

## 撮影後の流れ

1. **画像をzipにまとめて保管**（バックアップ）
2. Google Play Console の「ストアの設定」→「メイン ストアの掲載情報」へ
3. スクリーンショット欄にドラッグ&ドロップ
4. 並び順を調整（最も訴求力のある画像を1枚目に）
5. 公開前にプレビューで最終確認
